# job-flow

Simple Node.js + TypeScript HTTP server.

## Requirements

- Node.js 20+ (recommended)
- npm

## Setup

```bash
npm install
cp .env.example .env
```

Configure environment variables in `.env`:

| Variable | Description | Default |
| -------- | ----------- | ------- |
| `PORT`   | Port the HTTP server listens on | `8080` |

## Scripts

| Script | Command | Purpose |
| ------ | ------- | ------- |
| `npm run dev` | `tsx watch src/index.ts` | Start the server in development mode with live reload. Restarts automatically when files under `src/` change. |
| `npm run build` | `tsc` | Compile TypeScript from `src/` into JavaScript in `dist/`. |
| `npm start` | `node dist/index.js` | Run the compiled production build from `dist/`. Run `npm run build` first. |

Typical workflow:

```bash
# local development
npm run dev

# production-like run
npm run build
npm start
```

## Project structure

```text
src/
  index.ts      # HTTP server entry point
dist/           # compiled output (generated by build)
.env            # local env (not committed)
.env.example    # env template
```
